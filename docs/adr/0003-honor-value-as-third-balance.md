# 引入荣誉值作为第三种余额

会员体系需要展示赛事荣誉，但又不能影响等级和可兑换积分，因此在成长值与积分之外增加第三种余额“荣誉值”：只增不减，来源为赛事发放或管理员手动调整，不参与等级与积分兑换，并有独立的荣誉值明细与审计记录。实现上选择 `members.honor` 字段 + `honor_entries` 集合，而不是把 `point_entries` 泛化成通用账本，避免改动现有积分/成长值查询与双写逻辑，迁移成本更低。

Status: accepted
